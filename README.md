\# Student Performance and Risk Prediction



\## About the Project



This is a beginner machine learning project that I developed to explore student performance data and predict whether a student may be at risk based on academic and demographic information.



I built this project to gain practical experience with Python, data preprocessing, machine learning, and web application development.



\## Objectives



\* Explore and prepare student performance data.

\* Process categorical and numerical features.

\* Train a machine learning model to identify students at risk.

\* Build a simple interactive web application to demonstrate predictions.



\## Technologies Used



\* Python

\* Pandas and NumPy

\* Scikit-learn

\* Streamlit

\* Joblib



\## Machine Learning Approach



I used a Random Forest classifier with a preprocessing pipeline to train the model. The target variable was created to identify students at risk, and the final model was saved for use in the application.



\## Application



The project includes a Streamlit web application where users can interact with the model and explore student risk predictions.



\## What I Learned



Through this project, I gained hands-on experience with:



\* Preparing and processing datasets

\* Building a machine learning pipeline

\* Training and saving a classification model

\* Developing a simple web application

\* Organizing and managing a project using Git and GitHub



\## Project Structure



\* `app.py` — Streamlit application

\* `prepare\_data.py` — Data preparation

\* `train\_model.py` — Model training

\* `data/` — Dataset files

\* `models/` — Saved machine learning model
